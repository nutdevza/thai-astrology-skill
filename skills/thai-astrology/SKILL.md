# โหราศาสตร์ไทย (Thai Astrology) Skill

Skill นี้ช่วยให้ Claude พยากรณ์ดวงชะตาตามหลักโหราศาสตร์ไทยระบบหลัก (ดวงไทย/ลัคนา) ได้อย่างเป็นระบบ ตั้งแต่การผูกดวง การตีความ จนถึงการให้คำแนะนำเรื่องชื่อ ฤกษ์ และพยากรณ์รายช่วงเวลา

## ขอบเขตของ skill

Skill นี้ทำได้ 4 อย่างหลัก:

1. **ผูกดวง + พยากรณ์** : รับวัน/เวลา/สถานที่เกิด → คำนวณตำแหน่งดาว → วางลัคนา → ตีความ
2. **ตั้งชื่อมงคล** : วิเคราะห์อักษรชื่อตามหลักทักษาปกรณ์ 8 ดวง
3. **เลือกฤกษ์** : แนะนำช่วงเวลามงคลตามวัตถุประสงค์ (แต่งงาน ขึ้นบ้านใหม่ ฯลฯ)
4. **พยากรณ์รายวัน/รายปี** : ใช้ดวงจรเทียบกับดวงกำเนิด

## หลักการสำคัญที่ต้องยึดเสมอ

### 1. ตอบเป็นภาษาไทยล้วน

ทุกคำตอบในการพยากรณ์ การอธิบาย และผลลัพธ์ใช้ภาษาไทย ใช้ศัพท์โหรไทยดั้งเดิม (เช่น "ลัคนา" "ภพตนุ" "เกษตร" "อุจ") ไม่ใช้ทับศัพท์ภาษาอังกฤษเว้นแต่จำเป็น

### 2. ขอข้อมูลให้ครบก่อนเริ่ม — ใช้ AskUserQuestion

หากข้อมูลที่ผู้ใช้ให้มาไม่ครบ **ให้ใช้เครื่องมือ `AskUserQuestion`** เพื่อขอข้อมูลแบบมีโครงสร้าง (multi-choice) แทนการถามเป็นข้อความเปล่า ๆ — เพราะให้ผู้ใช้ตอบง่ายและไม่ต้องเสียเวลาพิมพ์ยาว

**ข้อมูลที่จำเป็นเสมอสำหรับการผูกดวง:**
- **วัน/เดือน/ปีเกิด** (พ.ศ. หรือ ค.ศ.)
- **เวลาเกิด** (HH:MM — ถ้าจำไม่ได้ ใช้ AskUserQuestion ถามว่าจะใช้ 12:00 น. ประมาณ หรือเลื่อนวันไป ทำไมลัคนาเปลี่ยนทุก 2 ชั่วโมง)
- **จังหวัด/อำเภอเกิด** (สำหรับพิกัด)

**ข้อมูลที่ควรถามต่อเพื่อปรับขอบเขตการพยากรณ์** (เลือกตามบริบท ไม่ต้องถามทุกข้อ):

| สถานการณ์ | สิ่งที่ควรถามด้วย AskUserQuestion |
|----------|-------------------------------------|
| ผู้ใช้ขอดูดวงรวม ๆ | ขอบเขต: ภาพรวม / เน้นการงาน / เน้นความรัก / เน้นสุขภาพ |
| ผู้ใช้ขอตั้งชื่อ | เป้าหมาย: เสริมเดช / เสริมศรี / เสริมอายุ / เสริมมูละ |
| ผู้ใช้ขอเลือกฤกษ์ | ระบุช่วงวันที่สะดวก (สั้น/ยาว) + ว่ามีข้อมูลคู่บ่าวสาวด้วยหรือไม่ |
| เวลาเกิดคลุมเครือ | ยอมรับลัคนาคลาดเคลื่อน / ขอประมาณช่วงเวลา (เช้า/บ่าย/เย็น) |
| ผู้ใช้ไม่เคยให้พิกัดที่เกิด | เลือกจังหวัดหลักที่รองรับ / ใส่ละติจูด-ลองจิจูดเอง |
| มีหลายระบบให้เลือก | ระบบดาว: Sayana (Tropical, default) / Nirayana (Lahiri) |

**ตัวอย่างการขอข้อมูลที่ดี** (สมมุติผู้ใช้บอกแค่ "ดูดวงให้หน่อย"):

```
ใช้ AskUserQuestion ถาม 2-3 คำถามพร้อมกัน:

1. "วัน/เดือน/ปีเกิด พ.ศ. อะไรครับ?" — แบบ open (ผู้ใช้จะตอบ "Other")
2. "เวลาเกิดประมาณกี่โมง?" (เช้า 06-12 / กลางวัน 12-18 / เย็น 18-24 / ดึก 00-06 / จำได้แม่น)
3. "ต้องการเน้นเรื่องอะไรเป็นพิเศษ?" (ภาพรวม / การงาน-การเงิน / ความรัก-คู่ครอง / สุขภาพ)
```

**หลักการสำคัญ:**
- ถามทีเดียวสูงสุด 2-4 คำถาม (ตามข้อจำกัด AskUserQuestion) อย่ายิงคำถามทีละข้อ
- ถ้าข้อมูลครบแล้ว **ห้ามถามซ้ำ** ให้ลงมือผูกดวงเลย
- ถ้าเป็นการ "ดูดวงต่อ" จากดวงเดิม (เช่น ดูดวงปีนี้) ไม่ต้องถามข้อมูลเกิดซ้ำ ให้ใช้ข้อมูลที่มี

### 2.1 เรียก context เพิ่มเมื่อพบโครงสร้างดวงพิเศษ

หลังจากผูกดวงเสร็จ ถ้าเจอ "โครงสร้างพิเศษ" ในดวง ให้ใช้ AskUserQuestion ถามผู้ใช้เพื่อตีความเชิงลึก เช่น

| สิ่งที่พบในดวง | คำถามที่ควรถามต่อ |
|---------------|---------------------|
| ดาวกระจุกในภพ ๑๒ | "ผู้ใช้สนใจปฏิบัติธรรม/จิตวิญญาณหรือไม่ เพราะดวงนี้มีพลังภพ ๑๒ มาก" |
| เสาร์เล็งภพ ๗ | "ผู้ใช้แต่งงานหรือยัง — มีคู่หรือไม่?" (เพื่อบอกได้แม่นว่าเสาร์ส่งผลอย่างไร) |
| ราหู-เกตุกุมดาวสำคัญ | "ผู้ใช้เคยมีเหตุการณ์ผิดปกติช่วงปี xx-xx ไหม?" (เพื่อยืนยันคุณภาพการพยากรณ์) |
| เจ้าเรือนการงานอ่อน | "ตอนนี้ผู้ใช้ประกอบอาชีพอะไร — สนใจเปลี่ยนสายงานไหม?" |

นี่ทำให้การพยากรณ์ **ไม่เป็นแบบ generic** แต่ปรับให้ตรงสถานการณ์จริงของผู้ใช้

### 3. ใช้ script คำนวณ ไม่เดาเอง

อย่าคำนวณตำแหน่งดาวเองโดยใช้สูตรในหัว เพราะจะคลาดเคลื่อน ให้รัน `scripts/cast_chart.py` เสมอ — script นี้ใช้ Swiss Ephemeris (pyswisseph) ซึ่งเป็นมาตรฐานระดับมืออาชีพ

### 4. แยก "ข้อเท็จจริงจากดวง" ออกจาก "การตีความ"

ในผลลัพธ์ ให้บอกชัดว่าส่วนไหนเป็นข้อมูลคำนวณ (เช่น "ลัคนาสถิตราศีเมษ องศา 15") และส่วนไหนเป็นการตีความ (เช่น "บ่งบอกว่าเจ้าชะตามีนิสัยกล้าหาญ") เพื่อให้ผู้อ่านแยกแยะได้

### 5. ระวังภาษาการพยากรณ์

หลีกเลี่ยงคำที่ฟันธงเรื่องร้ายแรง (เช่น "จะเสียชีวิตปี xx" "จะหย่าแน่นอน") ให้ใช้ภาษาที่เปิดทางเลือกและการแก้ดวง (เช่น "มีแนวโน้มที่ต้องระมัดระวัง" "ควรหาวิธีเสริมดวงด้านนี้") เพราะโหราศาสตร์ในวัฒนธรรมไทยมุ่งให้คำแนะนำมากกว่าฟันธงชะตา

### 6. ระวังการใช้ศัพท์เทคนิคเมื่อสื่อสารกับผู้ใช้ (สำคัญมาก)

ผู้ใช้ทั่วไป **ไม่ได้คุ้นกับศัพท์โหราศาสตร์** (ลัคนา ลัคนาธิปติ ภพ เกษตร อุจ มฤตยู ปรเกษตร นวางค์ ฤกษ์บน) ถึงแม้จะเป็นภาษาไทย ก็เป็นภาษาเทคนิคที่ต้องอธิบาย หลักการ:

**เมื่อใช้ AskUserQuestion:**
- **คำถาม/options ใช้ภาษาทั่วไป** ที่คนปกติเข้าใจ ไม่ใช้ศัพท์โหรอย่างเดียว
  - ❌ "ต้องการเสริมเดช-มูละ-อุตสาหะหรือไม่?"
  - ✅ "ต้องการเสริมด้านใด? — อำนาจ-ตำแหน่ง (เดช) / ครอบครัว-บ้าน (มูละ) / ความขยัน-งาน (อุตสาหะ)"
- ในช่อง `description` ของแต่ละ option ให้อธิบายสั้น ๆ ว่าหมายถึงอะไรในชีวิตจริง
- ถ้า option จำเป็นต้องใช้ศัพท์เทคนิค ให้วงเล็บคำแปลธรรมดาเสมอ

**เมื่อนำเสนอผลพยากรณ์:**
- ครั้งแรกที่ใช้ศัพท์โหร ให้วงเล็บคำอธิบายไว้ เช่น "ลัคนา (จุดบนท้องฟ้าด้านตะวันออกขณะเกิด — เป็นตัวแทนของเจ้าชะตา)"
- พอใช้คำเดิมในย่อหน้าถัดไป ก็ใช้ศัพท์โหรได้เลย ไม่ต้องอธิบายซ้ำ
- แยกชัดเจน 2 ส่วน: **"ข้อเท็จจริงจากดวง"** (ใช้ศัพท์โหรได้) กับ **"การตีความ"** (ภาษาทั่วไป)

**ปิดท้ายการตอบทุกครั้งด้วยข้อความเชิญถาม:**
```
> หากมีคำใดในคำพยากรณ์ที่ไม่เข้าใจ หรืออยากให้ขยายความในส่วนไหนเป็นพิเศษ
> สอบถามได้เลยนะคะ/ครับ ดิฉัน/ผมยินดีอธิบายเพิ่มเติม
```

**ถ้าผู้ใช้กลับคำถาม/สับสนกับ option ที่ให้ไป** (เช่น ถามว่า "เดชคืออะไร?"):
- อย่าตอบสั้น ๆ แล้วถามใหม่ — **อธิบายก่อน** ในระดับที่เข้าใจง่าย (1-2 ประโยค + ตัวอย่างชีวิตจริง)
- จากนั้นจึงถาม AskUserQuestion ใหม่ด้วย options ที่ปรับภาษาให้เข้าใจง่ายขึ้น

ตัวอย่างการอธิบายศัพท์โหรในภาษาทั่วไป:

| ศัพท์โหร | คำอธิบายในภาษาทั่วไป |
|----------|---------------------|
| ลัคนา | ราศีที่ขึ้นบนขอบฟ้าตอนเกิด — เป็นตัวแทนของคุณในดวง |
| ลัคนาธิปติ | ดาวที่ครองราศีของลัคนา — เปรียบเหมือน "ดาวประจำตัว" |
| ภพ | ห้อง/เรือน 12 ห้องในดวง แต่ละห้องดูเรื่องคนละแบบ (เช่น ห้องการงาน ห้องคู่ครอง) |
| เกษตร | ดาวอยู่ในราศีที่ตนเป็นเจ้าของ — มีกำลังเต็มที่ |
| อุจ | ดาวอยู่ในตำแหน่งดีที่สุด — ให้คุณยิ่งกว่าปกติ |
| ประ / นิจ | ดาวอยู่ในตำแหน่งอ่อนแอ — ให้โทษหรือผลไม่ดี |
| มฤตยู | ดาวยูเรนัส — บ่งการเปลี่ยนแปลงพลิกผัน |
| ฤกษ์บน | ช่วงเวลามงคลในกลางวัน (06:00-18:00) |
| ทักษา | ระบบจัดหมวดอักษรไทยตามวันเกิด ใช้ตั้งชื่อ |
| ฤกษ์ | ช่วง 1 ใน 27 ของวงรอบท้องฟ้า (นักษัตร) ที่ลัคนาหรือดาวตกอยู่ — บอกลักษณะพื้นฐานของเจ้าชะตา |
| ตรียางค์ | การแบ่งราศีออกเป็น 3 ส่วน ส่วนละ 10 องศา แต่ละส่วนมีดาวประจำ |
| ดิถี | ขึ้น/แรมกี่ค่ำ วัดจากระยะห่างระหว่างจันทร์กับอาทิตย์ |
| สายนะ / นิรายนะ | สองวิธีวางจุดเริ่มราศี — สายนะเริ่มที่วสันตวิษุวัต ส่วนนิรายนะถอย ~24 องศาไปอิงดาวฤกษ์ |
| กาลกิณี | หมวดอักษรที่ห้ามใช้ในชื่อ — ถือเป็นอักษรอัปมงคล |

## กระบวนการทำงาน

### กรณีที่ 1: ผูกดวงและพยากรณ์

```
1. ตรวจสอบข้อมูลที่ผู้ใช้ให้ — ถ้าไม่ครบ ใช้ AskUserQuestion (ดูข้อ 2 ด้านบน)
   - ต้องมี: วันเกิด, สถานที่เกิด
   - เวลาเกิด: ถ้าผู้ใช้ไม่ทราบเวลาเกิดจริง ไม่ต้องบล็อกด้วย AskUserQuestion — ปล่อย --time ว่างไว้ได้เลย
     สคริปต์จะ default เป็น 06:00 น. (สมมุติพระอาทิตย์ขึ้น ตามธรรมเนียมสุริยยาตร์ไทย) และแจ้งเตือนว่าลัคนา/ฤกษ์เป็นค่าประมาณ
     (อย่าใช้ 06:55 หรือค่าอื่นเป็น default เอง — ค่านี้ verify แล้วว่าให้ลัคนา/ฤกษ์คลาดเคลื่อนกับดวงจริง)
   - ควรถามด้วย: ขอบเขตการพยากรณ์ที่สนใจ (ภาพรวม/งาน/ความรัก/สุขภาพ)
2. รัน python scripts/cast_chart.py --date YYYY-MM-DD [--time HH:MM] --place "จังหวัด"
3. รับ output JSON: ตำแหน่งดาวทั้ง 10 ดวง + ลัคนา + ภพ 12
4. อ่าน references/bhava_meanings.md และ references/planet_standards.md ถ้ายังไม่อยู่ในความจำ
5. ตีความตามลำดับ:
   a. ดาวเจ้าเรือนลัคนา (ลัคนาธิปติ) อยู่ภพไหน → ภาพรวมชีวิต
   b. ดาวในแต่ละภพ + คุณภาพดาว (เกษตร/อุจ/ประ/นิจ)
   c. มุมสัมพันธ์สำคัญ (กุม เล็ง โยค ตรีโกณ)
6. ถ้าเจอโครงสร้างพิเศษ — ใช้ AskUserQuestion ถามผู้ใช้เพิ่ม (ดูข้อ 2.1 ด้านบน) เพื่อปรับการตีความ
7. นำเสนอตามรูปแบบใน "Template ผลลัพธ์การพยากรณ์" ด้านล่าง
```

### กรณีที่ 2: ตั้งชื่อมงคลตามทักษา

```
1. ตรวจข้อมูล — ถ้าไม่รู้ ใช้ AskUserQuestion ถาม:
   - "เด็กเกิดวันใด?" (อาทิตย์/จันทร์/อังคาร/พุธ/พฤหัส/ศุกร์/เสาร์)
     หมายเหตุ: ถ้าเป็นวันพุธ ต้องถามต่อว่ากลางวันหรือกลางคืน (พุธกลางวัน = เกิด 06:00-18:00)
   - "ต้องการเสริมด้านใดเป็นพิเศษ?" (เดช=อำนาจ / ศรี=ทรัพย์-เสน่ห์ / มูละ=ครอบครัว / อายุ=สุขภาพ)
   - ถ้ามีชื่อในใจอยู่แล้ว ขอให้ส่งชื่อนั้นมา
2. รัน python scripts/taksa.py --day <วัน> [--name "ชื่อ"]
3. อ่าน references/taksa_system.md ถ้าจำเป็น
4. ผลลัพธ์: ตารางอักษรในหมวด บริวาร/อายุ/เดช/ศรี/มูละ/อุตสาหะ/มนตรี/กาลกิณี
5. ถ้าผู้ใช้ยังไม่มีชื่อในใจ — ใช้ AskUserQuestion เสนอ 3-4 ชื่อตัวอย่างที่ตรงกับเป้าหมายที่เลือก
6. แนะนำว่า:
   - อักษรหมวด "ศรี" และ "เดช" — ใช้เป็นพยัญชนะต้นของชื่อ
   - อักษรหมวด "กาลกิณี" — ห้ามใช้เด็ดขาด
   - ถ้าผู้ใช้ระบุชื่อมาด้วย ให้วิเคราะห์ว่าอักษรทุกตัวอยู่หมวดอะไรบ้าง
```

### กรณีที่ 3: เลือกฤกษ์มงคล

```
1. ใช้ AskUserQuestion ถามครั้งเดียวให้ครบ:
   - "วัตถุประสงค์?" (แต่งงาน / ขึ้นบ้าน / เปิดร้าน / เดินทาง / ลงทุน / เริ่มงานใหม่)
   - "ช่วงเวลาที่สะดวก?" (สัปดาห์นี้ / เดือนนี้ / ระบุช่วงเอง — Other)
   - "มีข้อมูลดวงเจ้าชะตาเพิ่มเติมหรือไม่?" (มี — จะตรวจคู่ด้วย / ไม่มี — ดูภาพรวม)
2. รัน python scripts/auspicious_time.py --from YYYY-MM-DD --to YYYY-MM-DD --purpose <วัตถุประสงค์>
3. ถ้าผู้ใช้มีดวงเจ้าชะตา (จากกรณีที่ 1) ให้รัน cast_chart.py สำหรับวันที่ดีที่สุดเทียบกับดวงเจ้าชะตา
4. แนะนำวันที่:
   - หลีกเลี่ยงวันที่ดวงจันทร์อยู่ในภพอริ (6) หรือมรณะ (8) ของผู้ใช้
   - เลือกวันที่ดาวพฤหัสบดี/ศุกร์ทำมุมดีกับลัคนา
   - คำนึงถึง "ฤกษ์บน" (เวลา 06:00-18:00 ทั่วไป) และยามดี
5. นำเสนอ 3-5 วันให้ผู้ใช้เลือก พร้อมเหตุผลแต่ละวัน
```

### กรณีที่ 4: พยากรณ์รายวัน/รายปี

```
1. ตรวจสอบว่ามีดวงกำเนิดของผู้ใช้แล้วหรือไม่
   - ถ้ามี → ใช้เลย
   - ถ้าไม่มี → ใช้ AskUserQuestion ถามว่า "เคยให้ข้อมูลเกิดไว้แล้วหรือยัง?" และขอข้อมูลถ้ายัง
2. ใช้ AskUserQuestion ถามขอบเขต:
   - "ต้องการพยากรณ์ช่วงไหน?" (วันนี้ / สัปดาห์นี้ / เดือนนี้ / ปีนี้ / ระบุเอง)
   - "เน้นด้านใด?" (ภาพรวม / การงาน / การเงิน / ความรัก / สุขภาพ)
3. รัน scripts/cast_chart.py --date วันที่ปัจจุบัน/ปีที่ต้องการ → ได้ดวงจร
4. เทียบดวงจรกับดวงกำเนิด: ดาวจรไปทำมุมกับดาว/ภพไหนในดวงกำเนิด
5. ตีความเหตุการณ์ตาม "ภพที่ถูกกระทบ"
   เช่น: พฤหัสจรกุมเรือน 10 (กัมมะ) → การงานเจริญรุ่งเรือง
        เสาร์จรเล็งลัคนา → ช่วงนี้ติดขัด ระวังสุขภาพ
```

### กรณีที่ 5: เทียบสองระบบราศี (สายนะ vs นิรายนะ)

ใช้เมื่อผู้ใช้สงสัยว่าดวงที่โหรผูกให้ตรงกับการคำนวณหรือไม่ หรือเมื่อลัคนาอยู่ใกล้เส้นแบ่งราศี

```
python scripts/cast_chart.py --date YYYY-MM-DD --time HH:MM --lat .. --lon .. --compare
```

ผลลัพธ์เป็นตารางอ่านง่าย (เพิ่ม `--format json` ถ้าต้องการโครงสร้างข้อมูล) ประกอบด้วย
ลัคนาทั้งสองระบบพร้อมองศาสัมบูรณ์ · ค่า ayanamsa ณ วันเกิด · อัตราลัคนาเดินเป็นองศา/นาที ·
ระยะจากลัคนาถึงเส้นแบ่งราศีคิดเป็นนาทีของเวลาเกิด · ฤกษ์และเจ้าฤกษ์ · ตรียางค์และเจ้าตรียางค์ ·
ดิถี (ขึ้น/แรมกี่ค่ำ) · ตำแหน่งดาวและภพของทั้งสองระบบเทียบกัน

**วิธีอ่านผล:**

- **ราศีของลัคนาอย่างเดียวตัดสินระบบไม่ได้** เพราะสองระบบห่างกัน ~24° ซึ่งบางครั้งก็ยังตกราศีติดกัน
- **ฤกษ์กับตรียางค์เป็นตัวชี้ขาด** เพราะสองอย่างนี้ระบุองศาไม่ใช่แค่ราศี ถ้าโหรบอกฤกษ์หรือตรียางค์มา ให้ดูว่าตรงกับคอลัมน์ไหน
- **ภพของดาวมักเหมือนกันทั้งสองระบบ** เพราะลัคนากับดาวเลื่อนไปพร้อมกัน ความต่างจริงอยู่ที่ชื่อราศี มาตรฐานดาว (เกษตร/อุจ/นิจ) ฤกษ์ และตรียางค์
- **ดิถีไม่ขึ้นกับระบบ** ใช้เป็นจุดตรวจสอบกลางได้ เช่นถ้าโหรบอกว่า "ได้พระจันทร์ครึ่งเสี้ยว" ให้ดูว่าดิถีออกมาใกล้ขึ้น 8 ค่ำ หรือแรม 8 ค่ำ หรือไม่
- ถ้าบรรทัด "ใกล้เส้นแบ่ง" ขึ้นมา แปลว่าเวลาเกิดคลาดไม่กี่นาทีก็เปลี่ยนลัคนา ให้เตือนผู้ใช้ก่อนพยากรณ์

## Template ผลลัพธ์การพยากรณ์

ALWAYS ใช้โครงสร้างนี้สำหรับการพยากรณ์ดวงชาตา (ปรับให้กระชับหรือขยายตามขอบเขตที่ผู้ใช้ขอ):

```markdown
# พยากรณ์ดวงชะตา: [ชื่อ/ระบุผู้ขอ]

## ข้อมูลพื้นฐาน
- **วันเกิด**: [วันที่ พร้อมวันในสัปดาห์]
- **เวลาเกิด**: [HH:MM น.]
- **สถานที่เกิด**: [จังหวัด]
- **ลัคนาสถิต**: ราศี[ชื่อราศี] องศา [xx.xx°]
- **ดาวเจ้าเรือนลัคนา**: [ดาว] สถิตในภพ[xx]

## ตำแหน่งดาว
[ตารางหรือรายการ ดาว — ราศี — องศา — ภพ — มาตรฐาน(เกษตร/อุจ/ฯ)]

## ภาพรวมชีวิต (อ่านจากภพ 1 และดาวเจ้าเรือนลัคนา)
[2-4 ประโยค]

## ด้านการงานและทรัพย์สิน (ภพ 2, 10, 11)
[การตีความ]

## ด้านความรักและคู่ครอง (ภพ 5, 7)
[การตีความ]

## ด้านสุขภาพและอุปสรรค (ภพ 1, 6, 8)
[การตีความ]

## ดาวจรในช่วงนี้ (ถ้าผู้ใช้ขอ)
[เหตุการณ์ในช่วงเวลาปัจจุบัน]

## คำแนะนำการเสริมดวง
[สี ทิศ ของมงคล ตามคุณภาพดาวในดวง]

---
> หมายเหตุ: การพยากรณ์เป็นการชี้แนวโน้ม ไม่ใช่การฟันธง ขึ้นอยู่กับการกระทำของเจ้าชะตาด้วย
```

## ข้อจำกัดและการพึ่งพา

- ต้องติดตั้ง `pyswisseph` (`pip install pyswisseph`) สำหรับการคำนวณดาว
- หากไม่มี pyswisseph ติดตั้ง ให้ใช้โหมด fallback: ขอให้ผู้ใช้ผูกดวงจาก myhora.com/payakorn.com แล้วส่งผลให้ skill ตีความ

- สคริปต์รองรับสองระบบ: `--ayanamsa tropical` (สายนะ ดีฟอลต์) และ `--ayanamsa lahiri` (นิรายนะ)
